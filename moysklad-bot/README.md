# Telegram-бот учёта для цеха (МойСклад)

Бот для 5 сотрудников: приём расходов, доходов, отгрузок и прочих расходов прямо
в Telegram, с автоматической записью в уже существующий аккаунт МойСклад.
Владелец получает **автоматический отчёт каждый день** (остаток кассы +
доход/расход за день) прямо в Telegram, плюс может запросить его в любой
момент командой `/balance` (или `/today`).

## Как это работает

- Сотрудник пишет боту, выбирает кнопкой «Расход / Доход / Отгрузка / Прочий расход».
- Расход/доход/прочее → бот создаёт **расходный или приходный кассовый ордер**
  (`entity/cashout`, `entity/cashin`) в МойСклад с суммой и комментарием.
- Отгрузка → бот просит выбрать (или создать) клиента и один или несколько
  товаров из вашего каталога МойСклад, затем создаёт документ **«Отгрузка»**
  (`entity/demand`).
- Все записи попадают в тот же аккаунт МойСклад, которым вы пользуетесь 5 лет —
  ничего не дублируется, отчёты смотрите там же, где привыкли.

## Шаг 1. Получить токен Telegram-бота

1. Напишите [@BotFather](https://t.me/BotFather) в Telegram → `/newbot`.
2. Задайте имя и username бота.
3. Скопируйте выданный токен вида `123456789:AAAA...` — это `BOT_TOKEN`.

## Шаг 2. Получить API-токен МойСклад

1. Зайдите в МойСклад → **Настройки аккаунта → Обмен данными → API**.
2. Создайте токен доступа (или используйте логин/пароль — но токен надёжнее).
3. Это `MOYSKLAD_TOKEN`.

JSON API бесплатен на всех тарифах, включая бесплатный — регистрироваться отдельно
не нужно.

## Шаг 3. Узнать Telegram ID владельца и сотрудников

Каждый должен написать боту [@userinfobot](https://t.me/userinfobot) — он пришлёт
числовой ID. Соберите ID владельца (или нескольких) и всех 5 сотрудников.

## Шаг 4. Настроить и запустить

```bash
cd moysklad-bot
cp .env.example .env
# впишите в .env: BOT_TOKEN, MOYSKLAD_TOKEN, OWNER_IDS, EMPLOYEE_IDS
```

### Вариант А: локально / на своём сервере

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m bot.main
```

### Вариант Б: Docker (рекомендуется для постоянной работы)

```bash
docker compose up -d --build
```

Бот будет автоматически перезапускаться при сбоях (`restart: unless-stopped`).

Чтобы бот работал круглосуточно, его нужно разместить на сервере (подойдёт
самый дешёвый VPS, ~$3–5/мес) — просто на своём компьютере он будет отвечать,
только пока открыт терминал.

## Доступ

Отвечать боту могут только те, чей Telegram ID указан в `OWNER_IDS` или
`EMPLOYEE_IDS` в `.env`. Все остальные получат отказ. Владельцам дополнительно
доступны команды `/balance` и `/today` (алиасы одной и той же сводки).

## Остаток кассы и ежедневный отчёт

- Каждый день в `DAILY_REPORT_TIME` (по умолчанию 20:00, время сервера) бот
  сам присылает каждому владельцу: доход и расход за сегодня + текущий
  остаток кассы. Ничего запрашивать не нужно.
- Остаток бот пытается взять из встроенного отчёта МойСклад
  «Остатки по счетам/кассам» (`/report/money/byaccount`). Если этот отчёт
  недоступен на вашем тарифе — бот автоматически считает остаток сам, суммируя
  все приходные и расходные кассовые ордера за всё время. Это чуть медленнее
  при очень долгой истории, но работает без дополнительной настройки.

## Важно проверить перед боевым использованием

Код написан по документированной схеме JSON API МойСклад
(`https://dev.moysklad.ru/doc/api/remap/1.2/`), но у каждого аккаунта могут
быть свои обязательные поля (обязательные доп. поля, статьи расходов,
несколько организаций/складов и т.п.). Обязательно:

1. Заведите тестового сотрудника (свой Telegram ID) и проверьте все 4 сценария
   на реальном аккаунте МойСклад перед тем как раздавать доступ команде.
2. Если МойСклад вернёт ошибку валидации — она придёт прямо в чат с текстом
   ошибки от API; это подскажет, какое поле нужно доработать в
   `bot/moysklad.py`.
3. Если у вас несколько юрлиц или складов — сейчас бот берёт первую
   организацию и первый склад из списка (`get_default_organization_href`,
   `get_default_store_href`). При необходимости можно легко изменить на явный
   выбор из настроек.

## Структура проекта

```
moysklad-bot/
├── bot/
│   ├── config.py         # чтение .env
│   ├── moysklad.py       # клиент JSON API МойСклад
│   ├── keyboards.py      # inline-клавиатуры
│   ├── states.py         # состояния диалогов (FSM)
│   ├── main.py           # точка входа, контроль доступа
│   └── handlers/
│       ├── start.py      # /start, главное меню
│       ├── cash.py       # расход / доход / прочий расход
│       ├── shipment.py   # отгрузка (клиент + товары)
│       └── report.py     # /today — сводка для владельца
├── requirements.txt
├── .env.example
├── Dockerfile
└── docker-compose.yml
```
