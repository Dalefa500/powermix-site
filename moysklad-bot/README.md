# Telegram-бот учёта для цеха (МойСклад)

Бот для владельца и директора: быстрый ввод расходов/доходов прямо в
Telegram, с автоматической записью в уже существующий аккаунт МойСклад,
плюс отчёты — остаток кассы, доход/расход за выбранный период (день/месяц/
полгода/год), расход по каждому контрагенту (например, сколько потратил
директор) — по дням, по месяцам, итого — на основе ваших реальных 5 лет
данных в МойСклад, остатки на складе (отдельно по категориям) и
задолженность контрагентов.

Владелец и директор получают **автоматический отчёт каждый день** (доход,
расход и остаток кассы) прямо в Telegram, плюс могут запросить любой отчёт
в любой момент кнопкой в меню.

## Интерфейс

У бота закреплённое меню внизу экрана (как панель вкладок в обычном
приложении) — оно всегда на виду, не нужно листать переписку в поисках
кнопок: **💸 Расход · 💰 Доход · 📊 Баланс · 📅 Отчёт · 📦 Остатки · 📈 Долги ·
👥 Команда**. Кнопку можно нажать в любой момент, даже посреди ввода
другого действия — бот сам отменит текущий шаг и начнёт новый.

## Как это работает

- 💸/💰 → бот создаёт **расходный или приходный кассовый ордер**
  (`entity/cashout`, `entity/cashin`) в МойСклад с суммой и комментарием.
- 📊 Баланс → доход/расход за сегодня + текущий остаток в кассе/на счетах.
- 📅 Отчёт и 👥 Команда используют один и тот же выбор периода (**1 день /
  10 / 20 / 30 дней / 2–12 месяцев**) — определён один раз в `CP_PERIOD_DAYS`
  в `bot/keyboards.py`.
- 📅 Отчёт → показывает доход и расход за выбранный период (по дням — если
  период до ~3 месяцев, по месяцам — если больше) и итоговую прибыль.
- 👥 Команда → показывает расход по двум заранее заданным людям —
  **💼 Инвестор (вы)** и **👔 Убайд — директор** (под капотом это те же
  «Контрагенты» из МойСклад: «Дивиденды» и «Сулаймоншоев Убайд» — список
  задан в `TRACKED_COUNTERPARTIES` в `bot/handlers/report.py`, можно
  поменять состав или подписи там же). Выбираете человека — видите его
  расход за
  сегодня и разбивку (по дням или по месяцам, как и в «Отчёте») за тот же
  период, что выбрали в списке.
- 📦 Остатки → текущие остатки по товарам/сырью, сгруппированные по папкам
  МойСклад (`/report/stock/all`) — если сырьё и готовая продукция лежат в
  разных папках/категориях в самом МойСклад, бот покажет их отдельными
  блоками.
- 📈 Долги → задолженность контрагентов: кто должен вам, кому должны вы
  (`/report/counterparty`). На некоторых тарифах МойСклад это требует
  отдельно подключённой опции «Финансы» — если кнопка выдаёт ошибку прав
  доступа, проверьте её в МойСклад (Деньги → Взаиморасчёты).
- Все записи попадают в тот же аккаунт МойСклад, которым вы пользуетесь 5 лет —
  ничего не дублируется, полную историю смотрите там же, где привыкли.

## Шаг 1. Получить токен Telegram-бота

1. Напишите [@BotFather](https://t.me/BotFather) в Telegram → `/newbot`.
2. Задайте имя и username бота.
3. Скопируйте выданный токен вида `123456789:AAAA...` — это `BOT_TOKEN`.

## Шаг 2. Получить API-токен МойСклад

1. Зайдите в МойСклад → **Настройки аккаунта → Обмен данными → API**.
2. Создайте токен доступа (или используйте логин/пароль — но токен надёжнее).
3. Это `MOYSKLAD_TOKEN`.

JSON API бесплатен на всех тарифах, включая бесплатный — регистрироваться отдельно
не нужно.

## Шаг 3. Узнать Telegram ID владельца и директора

Каждый должен написать боту [@userinfobot](https://t.me/userinfobot) — он пришлёт
числовой ID.

## Шаг 4. Настроить и запустить

```bash
cd moysklad-bot
cp .env.example .env
# впишите в .env: BOT_TOKEN, MOYSKLAD_TOKEN, OWNER_IDS, DIRECTOR_IDS
```

### Вариант А: локально / на своём сервере

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m bot.main
```

### Вариант Б: Docker (рекомендуется для постоянной работы)

```bash
docker compose up -d --build
```

Бот будет автоматически перезапускаться при сбоях (`restart: unless-stopped`).

Чтобы бот работал круглосуточно, его нужно разместить на сервере (подойдёт
самый дешёвый VPS, ~$3–5/мес) — просто на своём компьютере он будет отвечать,
только пока открыт терминал.

## Шаг 5. Развернуть на сервере, чтобы бот работал 24/7

Бот работает через long polling (сам опрашивает Telegram), поэтому **не
нужно** ни открывать порты, ни настраивать домен/SSL — нужен только сервер с
исходящим доступом в интернет.

### 5.1. Арендовать VPS

Минимум: 1 vCPU, 512 МБ–1 ГБ RAM, Ubuntu 22.04/24.04 — этого более чем
достаточно. Варианты:
- Проще с оплатой из СНГ: Timeweb Cloud, REG.RU, Selectel — от ~150–250 ₽/мес.
- Международные (нужна карта с поддержкой валютных платежей): Hetzner
  (~€4/мес), Vultr, DigitalOcean, Contabo.

После оплаты провайдер пришлёт IP-адрес и пароль (или SSH-ключ) на почту.

### 5.2. Подключиться и поставить Docker

```bash
ssh root@ВАШ_IP
curl -fsSL https://get.docker.com | sh
```

### 5.3. Загрузить код бота на сервер

Через git (если репозиторий доступен с сервера):
```bash
git clone <URL_репозитория>
cd powermix-site/moysklad-bot
```

Или просто скопировать папку со своего компьютера:
```bash
scp -r moysklad-bot root@ВАШ_IP:/root/
ssh root@ВАШ_IP
cd moysklad-bot
```

### 5.4. Настроить .env и запустить

```bash
cp .env.example .env
nano .env   # впишите реальные BOT_TOKEN, MOYSKLAD_TOKEN, OWNER_IDS, DIRECTOR_IDS
docker compose up -d --build
```

### 5.5. Проверить, что бот работает

```bash
docker compose logs -f
```
(должна быть строка `Starting bot: ...`; `Ctrl+C` выходит из просмотра логов,
сам бот продолжает работать в фоне).

### 5.6. Автозапуск после перезагрузки сервера

- `restart: unless-stopped` в `docker-compose.yml` сам перезапускает
  контейнер при падении или перезагрузке.
- Убедитесь, что Docker стартует вместе с системой:
  ```bash
  systemctl enable docker
  ```

### 5.7. Обновление бота после изменений в коде

```bash
git pull        # или заново scp -r
docker compose up -d --build
```

## Доступ и кто что видит

Отвечать боту могут только те, чей Telegram ID указан в `OWNER_IDS` или
`DIRECTOR_IDS` в `.env`. Все остальные получат отказ.

И владелец, и директор видят одно и то же — полный доступ ко всем отчётам:

| Отчёт | Команда/кнопка |
|---|---|
| Доход/расход за сегодня + остаток кассы | `/balance` (или `/today`), 📊 Баланс |
| Доход/расход за период (день/месяц/полгода/год) | `/report`, 📅 Отчёт |
| Остатки на складе | `/stock`, 📦 Остатки |
| Задолженность контрагентов | `/debts`, 📈 Долги |
| Расход по команде (день/месяц/итого) | `/counterparties`, 👥 Команда |

Ежедневно в `DAILY_REPORT_TIME` бот сам присылает и владельцу, и директору
полный отчёт (доход/расход/остаток), без запроса.

Если понадобится добавить рядовых сотрудников (без доступа к цифрам дохода/
расхода — только к остатку кассы) — впишите их Telegram ID в `EMPLOYEE_IDS`
в `.env`, поддержка этой роли осталась в коде.

## Остаток кассы, остатки склада, долги — как это считается

- **Остаток кассы**: бот пытается взять его из встроенного отчёта МойСклад
  «Остатки по счетам/кассам» (`/report/money/byaccount`). Если этот отчёт
  недоступен на вашем тарифе — бот автоматически считает остаток сам,
  суммируя все приходные и расходные кассовые ордера за всё время.
- **Остатки склада**: берутся из `/report/stock/all` — то же самое, что вы
  видите в разделе «Товары → Остатки» в самом МойСклад.
- **Долги контрагентов**: берутся из `/report/counterparty`. Это менее
  распространённый отчёт в API, чем деньги/остатки — если при первом
  нажатии на «📈 Долги» придёт ошибка, пришлите её текст, разберёмся и
  поправим запрос под ваш аккаунт (как уже было с полем `agent` у
  кассовых ордеров).

## Важно проверить перед боевым использованием

Код написан по документированной схеме JSON API МойСклад
(`https://dev.moysklad.ru/doc/api/remap/1.2/`), но у каждого аккаунта могут
быть свои обязательные поля и права доступа токена. Если МойСклад вернёт
ошибку — она придёт прямо в чат с текстом ошибки от API; это подскажет,
что поправить в `bot/moysklad.py`.

```
├── Dockerfile

```
